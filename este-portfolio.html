Projeto

Este Portfólio

Site pessoal desenvolvido do zero para apresentar minha trajetória e projetos na área de equipamentos biomédicos.

📌 Sobre este projeto

Este site nasceu da necessidade de ter um espaço profissional e organizado para apresentar meus projetos, publicações e experiências na área de equipamentos biomédicos. O objetivo foi criar algo que fosse rápido, acessível, bonito e que funcionasse bem em qualquer dispositivo.

O projeto começou como um site estático em HTML/CSS/JS puro e, ao longo do tempo, foi migrado para Jekyll para facilitar a manutenção e a reutilização de componentes [reference:0]. Atualmente, ele está hospedado no GitHub Pages e passa por melhorias contínuas [reference:1].

🛠️ Tecnologias utilizadas

  • Jekyll – gerador de sites estáticos, que permite usar templates e manter o conteúdo organizado [reference:2].
  • HTML5 – estrutura semântica e acessível das páginas [reference:3].
  • CSS3 – estilização com variáveis nativas, flexbox, grid, animações e design responsivo [reference:4].
  • JavaScript (ES6+) – interatividade (menu mobile, modo escuro, lightbox, animações ao rolar) [reference:5].
  • Git & GitHub – controle de versão e hospedagem via GitHub Pages [reference:6].
  • Devicon & Font Awesome – ícones para tecnologias e ferramentas.

✨ Funcionalidades implementadas

  • Modo escuro (Dark Mode): suporte nativo com detecção de preferência do sistema e persistência via localStorage [reference:7].
  • Design responsivo: otimizado para celulares pequenos, tablets e monitores desktop [reference:8].
  • Menu mobile intuitivo: com suporte a gestos e tecla Escape para fechamento [reference:9].
  • Animações de surgimento (fade-in): ao rolar a página, utilizando Intersection Observer [reference:10].
  • Efeito cascata (stagger): nos cards de projetos e publicações, criando uma entrada fluida.
  • Sistema de "Ver Mais": para a seção de publicações [reference:11].
  • Botão "Voltar ao Topo": dinâmico, que aparece conforme a rolagem [reference:12].
  • Lightbox: para ampliação de imagens em projetos e publicações.
  • Acessibilidade e SEO: links de salto (skip-links), tratamento de erros de imagem (fallback), arquivo robots.txt e sitemap.xml [reference:13].
  • Página 404 personalizada: experiência de erro amigável e funcional [reference:14].
  • JSON-LD: dados estruturados para melhor indexação em mecanismos de busca.

📁 Estrutura do projeto

A organização dos arquivos foi pensada para ser modular e fácil de navegar [reference:15]: 

/
├── _data/             # Dados estruturados (Jekyll)
├── _includes/         # Partials reutilizáveis (navbar, footer)
├── _layouts/          # Layouts base (default.html)
├── images/            # Ativos visuais
│   ├── profile/       # Fotos de perfil
│   ├── projects/      # Imagens dos projetos
│   └── posts/         # Imagens das publicações
├── index.html         # Página inicial
├── sobre.html         # Sobre o autor (unificado com formação e experiências)
├── projetos.html      # Galeria de projetos
├── publicacoes.html   # Artigos e posts
├── conquistas.html    # Prêmios e reconhecimentos
├── contato.html       # Canais de comunicação
├── habilidades.html   # Habilidades técnicas
├── 404.html           # Página de erro personalizada
├── style.css          # Estilização global e responsividade
├── script.js          # Lógica, animações e configurações
├── sitemap.xml        # Mapa do site para SEO
├── robots.txt         # Instruções para rastreadores
├── _config.yml        # Configuração do Jekyll
├── Gemfile            # Dependências Ruby
└── README.md          # Documentação do projeto

🧠 Processo de desenvolvimento

O site foi construído de forma iterativa, com melhorias contínuas baseadas em feedback e aprendizado. Durante o processo, utilizei ferramentas de inteligência artificial (como DeepSeek, Grok e ChatGPT) como suporte para:

  • Refinar a estrutura HTML e a semântica das páginas.
  • Otimizar o CSS para responsividade e temas claro/escuro.
  • Implementar interações em JavaScript (menu mobile, lightbox, animações).
  • Corrigir bugs e melhorar a performance.
  • Garantir boas práticas de acessibilidade e SEO.

O uso dessas ferramentas foi parte do processo de aprendizado e não substituiu o trabalho manual de planejamento, design e decisões de arquitetura. Cada linha de código foi revisada e adaptada às necessidades específicas do projeto.

📊 Status atual

O site está ativo e em constante aperfeiçoamento [reference:16]. Atualmente, estou trabalhando em:

  • Aprimorar a experiência do usuário com microinterações.
  • Otimizar imagens para melhor performance (WebP).
  • Expandir a seção de projetos com novos conteúdos.
  • Refinar a acessibilidade e os dados estruturados.
